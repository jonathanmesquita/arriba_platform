Estudo de caso

Arriba Platform

Protótipo de estudos em fullstack: ferramentas de arquivo, SQL e rede que rodam no navegador, uma API privada e um app de chat com IA.

Todos os cases Chatbot com IA Deploy e DNS
Frontend

Vercel

Interface estática modular com HTML, CSS, Bootstrap e JavaScript.

Backend

Render + Node

API privada em api.arriba.jm.dev.br (outro repositório): validação, consultas a APIs públicas, painel de uso e IA no servidor.

DNS

Cloudflare

Gerenciamento de DNS, domínio principal e subdomínio da API.

IA

Base local primeiro

O chat responde pela base do site, sem rede; provedor de IA é opcional e, se falhar, volta para a base.

ADS na prática

A maior parte roda no navegador, de propósito.

Arquivo bancário, CSV, SQL e DNS são processados na máquina de quem usa: sem custo de servidor, sem subir dado e sem partida a frio. O servidor só entra onde é necessário (login, consultas externas, chave de IA), e cada escolha tem o porquê registrado no repositório (ADRs).
