Arquivo bancário · Padrão CNAB 240

Validar e gerar arquivo CNAB 240

Cole o conteúdo ou envie um arquivo .REM/.RET/.TXT de 240 posições. A tela confere o tamanho das linhas, a ordem dos registros (arquivo → lotes → detalhes), os totais dos trailers e, com um layout de banco escolhido, os campos de cada segmento. Também monta um arquivo de teste a partir dos campos obrigatórios. Tudo no navegador; nada é enviado a servidor.

Layout

Sem escolher um layout de banco, a tela confere só a estrutura, que vale para qualquer banco. Com o layout do Santander (cobrança) ou do Inter (pagamentos), confere também os campos de cada segmento e permite gerar um arquivo de teste.

Este layout tem lotes de tipos diferentes, e o conteúdo dos segmentos muda de um para outro. Para conferir um arquivo, não precisa escolher: o tipo vem do header de cada lote.

Arquivo

Dica: o arquivo é lido como texto Latin-1, o formato de troca dos bancos. Para conferir um arquivo do CNAB 400, use a tela do arquivo bancário (CNAB 400).

Linhas de outro tamanho são apontadas, e o conteúdo delas não é conferido (os campos ficariam deslocados).

O que esta tela confere

Em qualquer banco (estrutura)

  • Todas as linhas com 240 caracteres.
  • Código do banco (posições 1–3) e lote (4–7) numéricos.
  • Primeira linha Header de arquivo, com lote 0000; última linha Trailer de arquivo.
  • Cada lote: Header de lote → detalhes → Trailer de lote, com o mesmo número de lote.
  • Sequencial dos detalhes no lote (9–13) e código do segmento (14).
  • Totais do Trailer de arquivo (lotes e registros) e do Trailer de lote.

Com o layout do Santander (cobrança) ou do Inter (pagamentos)

  • Os campos de cada registro: tipo (número ou texto), datas DDMMAAAA, valores fixos e tabelas de códigos.
  • Regras do manual: vencimento, juros, desconto, abatimento, CPF/CNPJ do pagador, endereço e UF.
  • Santander: segmento P seguido de Q na remessa; T seguido de U no retorno. Inter: A seguido de B (TED e Pix), J seguido de J-52 (boletos e QR Code), O (tributos); o tipo do lote vem da forma de lançamento do header.
  • Gerar arquivo: Santander, segmentos P e Q (remessa) ou T e U (retorno); Inter, um lote de um dos cinco tipos. Lote e trailers são calculados.

Os layouts vêm dos manuais do Santander (H7815 v8.1, jun/2024) e do Inter (pagamentos, v1.10, ago/2024), sem arquivo real para comparar: a prova é a cobertura das 240 posições de cada registro, os exemplos dos próprios manuais e a ida e volta (gerar → ler). Os segmentos R, S e Y do Santander e o segmento C do Inter são lidos, mas a tela de geração não os monta. Veja o que cada padrão define em Padrões CNAB 240 e 400: o que cada um define.
