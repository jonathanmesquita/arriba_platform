Layout padrão dos arquivos CSV

Cada arquivo do modelo de dados, com as colunas na ordem em que aparecem. Separador ;, codificação UTF-8 com BOM, cabeçalho na primeira linha. A primeira coluna, Tipo_Registro, diz qual é o arquivo — é por ela que o Validador de CSV reconhece um arquivo solto.

Esta página é montada a partir de layouts-csv.js, a mesma fonte que o Gerador e o Validador usam. Coluna que entra ou sai do modelo aparece aqui sozinha — não há uma cópia escrita à mão para ficar desatualizada.
