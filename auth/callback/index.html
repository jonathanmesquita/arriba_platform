Callback OAuth

Endereço de retorno do login (Microsoft Entra ID). Recebe o que o provedor devolve, completa a troca do código pelo token via PKCE e mostra tudo decodificado — para acompanhar e depurar o fluxo pelo navegador.

Configuração do aplicativo

Aparece na visão geral do registro no portal do Azure. Não é segredo.

Também público — vai na própria URL de autorização.

Registre exatamente esta URI no portal, em Autenticação → Adicionar plataforma → Aplicativo de página única (SPA). Não use a plataforma “Web”: ela exige client secret, que um site estático não pode guardar.

Histórico de retornos

ℹ️ Tudo roda no seu navegador. O fluxo é Authorization Code + PKCE, sem client secret — que é o correto para site estático, onde qualquer segredo embarcado seria público. O code_verifier e o state ficam em sessionStorage (somem ao fechar a aba); a configuração, que não é segredo, fica em localStorage. O token é exibido mas não é guardado, e a assinatura dele não é verificada aqui — validação de assinatura exige as chaves públicas do provedor e pertence a quem consome o token, não a esta página.
