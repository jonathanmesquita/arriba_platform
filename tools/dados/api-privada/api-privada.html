Validar e consultar pela API

Esta tela chama a Arriba API, o backend do projeto: valida CPF, CNPJ, e-mail, celular, CSV e JSON, e consulta CEP, CNPJ e bancos em APIs públicas e gratuitas.

A API é privada: só responde a quem entra. A chave de acesso não está no código desta página — um site estático não guarda segredo, tudo que vem para o navegador é público.

A chave fica só na memória desta aba: some ao recarregar e não é gravada no navegador. Use em computador seu — qualquer extensão do navegador enxerga o que se digita.

Como esta tela protege o acesso. O login cria um cookie HttpOnly: o navegador manda junto em cada chamada, mas nenhum script consegue ler o valor nem levá-lo para outro lugar. Funciona porque o site e a API são o mesmo site (arriba.jm.dev.br e api.arriba.jm.dev.br) e a API só libera CORS para esta origem. Dez senhas erradas em 15 minutos travam o login. Documento validado vai no corpo da requisição, não na URL, para não ficar gravado em log.
