Arquivo bancário · Padrão CNAB 240

Conferir a estrutura de um arquivo CNAB 240

Cole o conteúdo ou envie um arquivo .REM/.RET/.TXT de 240 posições. A tela confere o tamanho das linhas, a ordem dos registros (arquivo → lotes → detalhes), os números de lote e os totais dos trailers. Tudo no navegador; nada é enviado a servidor.

Arquivo

Dica: o arquivo é lido como texto Latin-1, o formato de troca dos bancos. Para conferir um arquivo do CNAB 400, use a tela do arquivo bancário (CNAB 400).

Linhas de outro tamanho são apontadas, e o conteúdo delas não é conferido (os campos ficariam deslocados).

Resultado

O que esta tela confere — e o que não confere

Confere

  • Todas as linhas com 240 caracteres.
  • Código do banco (posições 1–3) e lote (4–7) numéricos.
  • Primeira linha Header de arquivo, com lote 0000; última linha Trailer de arquivo.
  • Cada lote: Header de lote → detalhes → Trailer de lote, com o mesmo número de lote.
  • Sequencial dos detalhes no lote (9–13) e código do segmento (14).
  • Totais do Trailer de arquivo (lotes e registros) e do Trailer de lote.

Não confere

  • Os campos dentro de cada segmento (valores, datas, nosso número, ocorrências): cada banco adapta o layout, e sem o manual do banco qualquer regra ali seria palpite.
  • Dígito verificador do nosso número e tabelas de códigos por banco.
  • Não há modo "gerar" para o 240 pelo mesmo motivo; o CNAB 400 gera arquivo para três bancos.
