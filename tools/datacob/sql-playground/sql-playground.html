DataCob · Simulador SQL

SQL Playground

Escreva e rode consultas livres contra um banco de treino com a mesma estrutura de tabelas do DataCob (Financiado, Contrato, Parcela, Acordo, Historico...), com dados 100% fictícios. Roda inteiramente no seu navegador — nenhuma conexão com o SQL Server real, nada é enviado a servidor. Seu histórico e suas consultas salvas ficam só nesta máquina.

Tabelas

Clique numa tabela para ver colunas e chaves. Use os botões para jogar um SELECT no editor.

Editor de consultas

Digite qualquer SELECT (JOIN, GROUP BY, subquery, CASE...) e clique em Executar. O motor é o AlaSQL, que cobre a maior parte do T-SQL de leitura — funções muito específicas do SQL Server podem não existir aqui.
